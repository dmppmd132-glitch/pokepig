v1.7（2026-10-30）道具、出口、稀有怪技能表

新增

道具「脫逃繩」：只能在迷宮使用，用掉後回到火山的迷宮入口。商店 70 金幣。
道具「補血藥」：背包使用，可選隊伍任一隻回復 40 體力（沒力的不能用）。商店 40 金幣。
稀有以上怪物（10 隻新增稀有怪、7 隻傳說、夢幻兔豬皇、鈺兔兔，共 19 隻）有各自的升級學習技能表：
稀有怪約 Lv6／12／18／24 起依序學三招同屬性招式（氣彈、波動、風暴）與一招專屬招式。
傳說、夢幻兔豬皇、鈺兔兔本來就有固定強招，新技能表從 Lv32 起學習。

調整

城市出口不再全在右邊：水族城、花語城出口改在下方，烈焰城出口改在上方（對應城市的入口位置一併調整）。
商店、背包的右側選單改為一次顯示 3 項並可捲動，選項不會再掉出畫面。
學習新招式的提示改用實際的怪物名字；招式欄未滿四招時直接學會。
v1.6（2026-10-30）八項改良
電腦盒子「取出」：翻頁不再跳回上層選單，每頁 4 隻並新增「返回」。
圖鑑與隊伍畫面：招式名稱分兩行顯示，不再被切掉。
隊伍畫面可調整出戰順序（A 選取、再按 A 對調），最前面還活著的怪物先出場。
新增戰鬥音效：出招、命中、被打、效果絕佳、沒命中、回血、收服、升級、勝利。
城市加入牆壁與繞路，不再從左直走到右；月影森林也加了繞路。
7 隻傳說怪物各有專屬洞穴地圖（炎皇豬：烈焰城、月兔仙子：花語城、雲海兔王：海域、赤焰豬神：火山、雪月兔神：冰晶城、雷霆豬王：雷鳴城、星耀豬皇：迷宮深處）。
普通飼料改為無限（背包顯示「飼料∞」）。
豬豬鎮新增獨立的「商店」建築（有招牌），店員在店內櫃台後。
v1.5（2026-10-30）每個城市專屬配樂
月影森林、水族城、星學堂、花語城、雷鳴城、烈焰城、礦石城、冰晶城、海域、火山、迷宮各有自己的配樂。
